STOCKBUDDY 1.0 - your friendly daily stock helper
==================================================

StockBuddy reads stockanalysis.com, WallStreetZen, Reddit (r/ValueInvesting,
r/options, r/wallstreetbets), your Stock Rover export and StockCharts-style
chart signals. It then explains in plain English the day's best buys, sells,
options, shorts and 0DTE ideas, and how the world's biggest stock markets are
doing.

IMPORTANT: StockBuddy is a learning and research helper, NOT a financial
advisor. It can be wrong, data can be late, and you can lose money. Never
invest money you can't afford to lose.

Pick the folder for your device:


WINDOWS (Windows 10 or 11)
--------------------------
1. Right-click the downloaded zip file and choose "Extract All...", then
   click "Extract".
2. Open the "Windows" folder and double-click "Install StockBuddy".
   - If Windows says "Windows protected your PC", click "More info" and then
     "Run anyway". This appears because StockBuddy is a new app that Windows
     doesn't know yet.
   - If you don't have Java, the installer offers to install it for you.
     Java is free, and StockBuddy needs it to run.
3. When it's finished you'll have two new icons on your Desktop:
     StockBuddy         - the main app
     StockBuddy Widget  - just the small panel that stays on your desktop
4. To remove it later: Start menu > StockBuddy > Uninstall StockBuddy.


LINUX (64-bit PC: Ubuntu, Mint, Fedora, Debian...)
--------------------------------------------------
1. Extract the zip (right-click > "Extract Here").
2. Open a terminal in the "Linux" folder and type:
       bash install.sh
   Java is already built in, so nothing else needs installing on a normal
   64-bit PC.
3. Open StockBuddy from your apps menu (search "StockBuddy") or from the
   Desktop icon. You can also type "stockbuddy" in a terminal.
   - If the Desktop icon shows a warning, right-click it and choose
     "Allow Launching".
4. To remove it later:  ~/.local/share/stockbuddy/uninstall.sh


ANDROID (Android 8.0 or newer)
------------------------------
See "Android/How to install on Android.txt".
Short version: copy StockBuddy.apk to your phone, tap it, and allow
"Install unknown apps" when asked. The Android version also has a
home-screen widget.


TIPS FOR BEGINNERS
------------------
- Start with "Practice mode". It uses made-up data, so you can learn safely.
- Use the Skin button to choose colours you like. The desktop widget can
  have its own skin too: right-click it.
- Try ideas with "paper trading" (fake money in your broker's app) before
  using real money.

The "Source code" folder has everything needed to change or rebuild
StockBuddy (see README.md inside it). You don't need it to use the app.
